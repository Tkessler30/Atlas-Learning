# Atlas v0.7 Learning Depth Research

## What Atlas borrows as design principles (not copied content/UI)

- Duolingo: short sequential interactions, adaptive difficulty, mistakes revisited later, spacing.
- Khan Academy: instruction before practice, hints/retry, skill mastery that can move up or down, later mastery challenges.
- Brilliant: visual intuition, step-by-step problem solving, active prediction before reveal, progressive paths.
- Coursera: authentic real-world projects and guided application.
- Quizlet Learn: adaptive active recall, varied checks, weak-area targeting.
- Anki/FSRS: review timing based on estimated retrievability rather than fixed review dates.

## Atlas v0.7 lesson contract

A daily lesson is no longer one summary card. It is a guided sequence:

1. Orient — goal, vocabulary, why the concept matters in today's arc.
2. Build the model — direct instruction and the mechanism.
3. Deepen — second layer, connections, misconceptions.
4. Worked example — learner predicts first, then reveals the full solution.
5. Practice with support — learner works before moving on; hint available.
6. Transfer / self-explanation — learner explains the concept in a new situation.
7. Mastery check — concept-specific, with "I don't know yet" and feedback.
8. Sources & next steps — exact lesson sources when available plus a trusted subject research shelf.

## Push beyond existing apps

- Daily sessions are cross-domain only when a real causal/system connection exists.
- Breadth is optimized across the week, not by random subject switching within a day.
- Atlas separates placement estimates, exposure, direct learning evidence, retention and transfer.
- Within-lesson stage state is saved locally so a learner can return to the same instructional step.
- Sources have explicit reuse notes so a future commercial product does not accidentally treat "available on the web" as "free to copy."
- A learning object that lacks real instructional content or a legitimate source path is labeled unavailable rather than disguised as teaching.

## Content limitation

The engine can now support deep lessons across the full map, but full source-backed coverage of all routable concepts still requires either:
1. a configured personalized AI content provider using the trusted-source policy, or
2. continued authoring/verification of Atlas Core lessons.

The current bundled core library is not falsely represented as equivalent in volume to mature course platforms.
